# 운영 가이드

일산호수공원과 주변 장소를 안내하는 산책 지도 서비스의 운영 절차입니다.

## 서비스와 배포

- 서비스: Railway `local-map` 프로젝트의 `local-map` 서비스, `production` 환경
- 공개 주소: <https://local-map-production.up.railway.app>
- 소스 저장소: <https://github.com/yeonjun7724/local-map>
- 재배포: 저장소 루트에서 Railway CLI가 production 프로젝트·서비스에 연결된 것을 확인하고 `railway up --ci`를 실행합니다. 빌드와 배포가 성공했는지 Railway 배포 내역에서 확인한 뒤 공개 페이지가 응답하는지 점검합니다.
- 변수 관리: Railway 프로젝트의 `local-map` 서비스 → `production` → **Variables**에서 설정합니다. `NEXT_PUBLIC_GA_ID`는 브라우저에 공개되는 측정 ID이며, OpenAI 등 비밀 키를 `NEXT_PUBLIC_` 이름으로 만들지 않습니다. `.env.local`은 로컬 개발용으로만 사용하고 저장소에 올리지 않습니다.
- 비용 확인: Railway 프로젝트의 **Usage**에서 현재 사용량과 청구 금액을 확인합니다. 매월 사용량 추이를 점검하고 불필요한 서비스나 예상 밖의 증가를 조사합니다.

## 이 지도의 운영 특성

- 지도는 공원 산책로·정원·수변·분수 등 야외 장소와 주변 카페·음식점을 함께 다룹니다. 야외 시설은 계절, 날씨, 행사 및 시설 정비에 따라 이용 가능 여부나 가동 시간이 달라질 수 있습니다.
- 현재 장소 데이터는 44곳이며 카페 11곳과 음식점 6곳이 포함되어 있습니다. 검토 시점에 `openingHours`가 입력된 장소는 없습니다. 카페·음식점은 휴무일과 영업시간이 바뀔 수 있으므로 확인되지 않은 시간을 임의로 표시하지 말고, 방문 전에 운영자나 공식 안내에서 최신 정보를 확인하도록 안내합니다.
- 장소 좌표와 OSM 보행 경로는 현장 출입구·통행 가능 여부·유모차 접근성을 보증하지 않습니다. 지도나 경로 데이터를 갱신할 때 출처와 검증 상태를 보존하고, 확인되지 않은 경로를 실제 안내로 과장하지 않습니다.
- 장소 정보 변경은 근거 출처와 확인일을 함께 기록하고, 영문명·설명과 한국어 정보가 서로 맞는지 확인합니다.

## 키 유출 대응

키가 코드, 커밋, 로그, 화면 공유 또는 메시지에 노출되면 노출된 키가 악용됐다고 간주하고 다음 순서를 따릅니다.

1. **폐기** — 키를 발급한 서비스에서 노출된 키를 즉시 비활성화하거나 폐기합니다.
2. **재발급** — 해당 서비스에서 새 키를 발급합니다.
3. **Railway Variables 교체** — Railway `local-map` 서비스의 `production` 환경에서 해당 변수 값을 새 키로 바꿉니다. 키 값은 채팅·커밋·로그에 붙여 넣지 않습니다.
4. **재배포** — 저장소 루트에서 `railway up --ci`를 실행하고 새 배포가 성공했는지 확인합니다.
5. **검증** — 연동이 정상 동작하는지 확인하고, 폐기된 키를 사용한 흔적과 불필요한 로그 노출이 없는지 점검합니다.

## 방문 통계와 개인정보

페이지 조회는 페이지가 열린 횟수이며 코스 인기도와 같지 않습니다. 코스 선택은 `route_open`으로 별도 확인하고, 추천 결과 요청은 `recommend` 이벤트로 확인합니다. 조회 수만으로 코스 선호도를 단정하지 않습니다.

| 이벤트 | 전송 값 | 의미 |
|---|---|---|
| `route_open` | `route_id` | 방문자가 산책 코스를 선택함 |
| `place_open` | `place_id`, `category` | 방문자가 장소 상세를 엶 |
| `share` | `scope` (`map`, `route`, `place`) | 공유 링크를 복사함 |
| `qr_download` | `scope` (`map`, `route`, `place`) | QR 파일을 저장함 |
| `recommend` | `source`, `minutes`, `theme`, `companion` | 조건에 맞는 추천 결과를 받음 |

다음 정보는 사용자 이벤트 매개변수로 보내지 않습니다.

- 장소 좌표
- 검색어
- 찜 목록
- 사용자의 코스 전체 장소 ID 목록
- 이름·이메일·전화번호 등 개인 식별 정보

이벤트 매개변수를 추가하거나 변경할 때는 위 금지 목록을 지키고, 페이지 조회와 코스·장소 상호작용 이벤트를 구분해 해석합니다.
